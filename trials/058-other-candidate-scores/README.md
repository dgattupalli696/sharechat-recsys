# T058 – Other candidates’ watch predictions

Hypothesis: the strength and distribution of competing videos’ predicted watch probabilities contain information beyond row score and request size. Compare one frozen 160-round, 15-leaf LightGBM residual correction per arm, with the original XGBoost logit as offset. Control uses own logit and request size; treatment adds leave-one-out logit mean/std, sum of probabilities, max peer logit, margin to max, and probability at least one peer is watched under independence. Singleton peer summaries are missing. Train on saved T057 inner-pooled forward predictions (later quarter of primary fit rows); evaluate on the entire original holdout using T054-A. Same six-way rank blend, replacing only the XGBoost component. No tuning on this holdout; original incumbent is holdout-selected. Require +0.0003 blend AUC vs A and improvement vs matched control to advance. Fixed seed 42. Run `python trials/058-other-candidate-scores/run.py` from repository root. Record wall time and 400 paired request bootstraps in results.json. Source baseline 6238c1a plus local T054/T055/T057 artifacts. No submission.
