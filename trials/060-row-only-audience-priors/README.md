# T060 – row-only audience and content priors

Matched T059 CPU depth12 XGBoost (seed 42, 900 rounds) with 26 extra features: 9 singleton and 4 audience/content key pairs, using log training counts and watch probability shrunk by 40 observations toward the training-prefix mean. Raw keys and pairs are fixed in run.py. Different from T019's user ID, item ID and user×item histories: here audience-profile and content-cohort keys generalize to unseen viewers. No request ID read. Training lookups are fitted on strictly earlier timestamp blocks, with the first 10% warmup set missing. Each validation row queries a frozen lookup learned on the full training prefix. Unseen keys receive zero count and training mean. Test lookup would follow exactly the same policy.

Reuse T059 matrices; fixed probability ensemble 75% T016 + 25% candidate. Compare global ROC AUC to both T016 and the matched T059 blend on all 307,528 primary holdout rows. Require positive incremental gain and +0.0003 over T016 to advance to an earlier fold. Validate lookup and prediction batch invariance. Run `.venv/bin/python trials/060-row-only-audience-priors/run.py` after T059. Metrics and runtime written to results.json; artifacts/log under artifacts/local-t060. Source baseline 6238c1a plus T059. No competition submission.
